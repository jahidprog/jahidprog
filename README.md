## 🔬 Featured Work

**👁️ CAS-FD: Foul vs. Dive Recognition** · *Contact-Aware Temporal Sampling for Single-View Foul vs. Dive Recognition*
Can a model tell a real foul from a dramatic dive using just one camera angle? Turns out yes. A **YOLO-driven contact-aware sampler** picks the frames that matter, then **VideoMAE-Base** does the classification.
🎯 **86.0%** test accuracy on a 600-clip single-view dataset · 🤗 [Dataset on Hugging Face](https://huggingface.co/datasets/jahid114593/foul-vs-dive-dataset) · 📝 Thesis complete [Paper](https://arxiv.org/abs/2608.17060)
