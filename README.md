## 🔬 Featured Work

### 👁️ CAS-FD: Foul vs. Dive Recognition
> *Contact-Aware Temporal Sampling for Single-View Foul vs. Dive Recognition*

Can a model tell a real foul from a dramatic dive using just one camera angle? Turns out yes.
A **YOLO-driven contact-aware sampler** picks the frames that matter, then **VideoMAE-Base** does the classification.

- 🎯 **86.0%** test accuracy on a 600-clip single-view dataset
- 🤗 Dataset is public on [Hugging Face](https://huggingface.co/datasets/jahid114593/foul-vs-dive-dataset)
- 📝 Thesis complete [Paper](https://arxiv.org/abs/2608.17060)

`PyTorch` `VideoMAE` `YOLO` `Computer Vision` `Temporal Sampling`

### 🚗 ADAS Lane Detection
Lane detection pipeline for driver-assistance systems.

### 🛒 SportNest: Full-Stack E-Commerce
Production-style commerce platform. **Go** backend with plain `net/http` (no framework crutches), **Next.js 14 + TypeScript + Tailwind** frontend.

- Products, orders, categories, banners, image uploads
- Google Sign-In + WhatsApp order notifications
- Feature-complete admin dashboard
- Security-hardened backend

👉 [backend-go](https://github.com/jahid.prog/backend-go)
